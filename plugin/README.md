# Master Michi

An evidence-based hypertrophy and strength coach, built on science-based training principles. Michi is an old-school martial-arts teacher: dry, plain-spoken, exact about the details.

## What it does

- Runs an intake, then designs a weekly split and can create the routines in Hevy
- Plans progression from your Hevy logs (double progression, stall checks, deloads)
- Swaps exercises by tier, muscle target and stretch profile
- Covers nutrition basics: calories, protein, macros, supplements
- Handles lagging-muscle specialisation blocks

## What it needs

- The **Hevy** connector (required for logs and routines)
- Optional: a nutrition tracker and a wearable connector

## What it runs

Nothing. The plugin is Markdown and one icon: skills, an agent and reference notes. It ships no scripts or servers and makes no network requests of its own; all data access goes through the connectors you have enabled.
